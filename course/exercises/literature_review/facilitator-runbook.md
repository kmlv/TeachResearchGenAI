# Runbook de facilitación — revisión de literatura (35 minutos)

## Resultado docente

Al terminar, la sala debe poder explicar y reutilizar un flujo de seis
artefactos: pregunta, protocolo, registro de búsqueda, tabla de candidatos,
matriz de evidencia y síntesis. Debe saber que el mismo flujo funciona en un
proyecto de ChatGPT/Claude o en una carpeta local con Codex/Claude Code.

## Antes de la clase (10 minutos)

1. Renderizar el deck y comprobar sus tres enlaces: clip, guía y práctica.
2. Abrir `discovery-screening-clip.html` y dejarlo en pausa.
3. Abrir `participant-packet.html` y la clave en una ventana no proyectada.
4. Ejecutar `python3 starter_workspace/validate_workspace.py`.
5. Tener `fallback-matrix.md` disponible si falla un asistente.
6. No instalar Codex, Claude Code, Zotero, Rayyan ni ASReview durante los 35
   minutos. La instalación es una ruta posterior, no el aprendizaje central.

## Guion minuto a minuto

| Minuto | Acción | Producto visible |
|---:|---|---|
| 0–3 | Fijar el resultado y mostrar los seis archivos | Flujo reproducible |
| 3–5 | Mapear opciones gratuitas, abiertas o ya disponibles | Una por etapa |
| 5–8 | Reproducir el clip de persuasión | Consulta, criterios y razones |
| 8–12 | Comparar chat y carpeta local; abrir el workspace | Mismo método, dos superficies |
| 12–16 | Mostrar inicio en Codex/Claude Code y cuatro barreras | Reglas persistentes |
| 16–22 | Mostrar cuatro solicitudes y sus artefactos | Cribado → extracción → auditoría → síntesis |
| 22–23 | Abrir el corpus Juntos y formar parejas | A1, A2 o A3 asignada |
| 23–26 | Ejecutar el prompt común | Tabla provisional |
| 26–32 | Auditar una sola afirmación por pareja | Fila corregida |
| 32–33.5 | Debrief: país, resultado y causalidad | Tres errores visibles |
| 33.5–34.5 | Redactar tres oraciones | Mini-síntesis |
| 34.5–35 | Enlazar guía y workspace | Ruta para continuar |

## Qué demostrar y qué no

**Mostrar en vivo:** el clip, la estructura de la carpeta, las solicitudes
exactas, el diff como concepto y la práctica sobre el corpus congelado.

**No mostrar en vivo:** instalaciones, autenticación, APIs, MCP, búsquedas
abiertas que puedan variar, comparación de respuestas entre modelos ni una
configuración avanzada de Zotero.

**Diapositiva prescindible si hay retraso:** omitir «Cuatro solicitudes, cuatro
productos» (16–18) y entrar directamente en «Cribar no es resumir». No recortar
la auditoría 26–32 ni el cierre de síntesis.

## Frase de transición entre superficies

> «En un proyecto de ChatGPT o Claude, ustedes suben estos archivos. En Codex o
> Claude Code, el agente abre la carpeta directamente, edita y valida. Lo que
> importa no es la superficie: son los archivos y quién puede cerrar cada
> decisión.»

## Si algo falla

- **Sin asistente:** proyectar `fallback-matrix.md`; auditarla produce el mismo
  aprendizaje.
- **Sin clip:** narrar sus tres decisiones: incluir, excluir por población y
  separar por advertencia editorial.
- **Sin terminal o agente de código:** usar la ruta de proyecto con archivos
  subidos; no intentar instalar nada.
- **El modelo busca fuera del corpus:** detenerlo y repetir la frontera de
  fuentes. Registrar una búsqueda nueva solo como otra etapa.
- **Se consume el tiempo:** resolver A3 y A2 en plenario; conservar el cierre
  sobre los seis artefactos. Si el retraso ocurre antes de la práctica, usar la
  diapositiva prescindible indicada arriba para recuperar dos minutos.
