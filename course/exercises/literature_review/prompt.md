# Prompt común: extracción, no síntesis

Copiar y pegar después de los cuatro pasajes y de A1–A3:

```text
Trabaja exclusivamente con los pasajes proporcionados. No uses memoria,
conocimiento externo ni nuevas búsquedas.

Para cada afirmación A1–A3, devuelve una tabla Markdown con estas columnas:

1. ID de afirmación
2. veredicto: respaldada, contradicha, parcialmente respaldada o evidencia insuficiente
3. fuente y programa/país
4. fragmento textual exacto o NO ENCONTRADO
5. localizador disponible
6. qué permite concluir el diseño y el pasaje
7. qué no permite concluir
8. aspecto que requiere verificación humana

Reglas:
- Si no hay pasaje que apoye una parte de la afirmación, escribe NO ENCONTRADO.
- Distingue programa, país, población, resultado y tipo de diseño.
- No redactes una síntesis ni inventes una cita.
- No conviertas matrícula, asistencia o transición escolar en aprendizaje.
```

**Uso correcto:** la tabla es una propuesta de extracción. La pareja debe
corregir una fila contra `sources.md` antes de que la sala la use para sintetizar.
