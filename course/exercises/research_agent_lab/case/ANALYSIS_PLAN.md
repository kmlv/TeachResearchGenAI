# Registered plan for the synthetic case

- Population: workers in the synthetic urban cohort with baseline employment.
- Exposure: baseline one-way commute duration in minutes.
- Outcome: same-employer status twelve months later.
- Primary estimand: adjusted associational risk difference per 30 additional minutes.
- Adjustment set: age, education, household composition, and district.
- Job type: measured, omitted from the registered primary model; any analysis that
  adds it must be labelled exploratory and interpreted as a discriminating check.
- Missing outcome: primary coding treats missing as non-retention; requested
  sensitivity should report complete-case and best/worst bounds.
