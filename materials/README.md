# Materiales públicos

Este directorio contiene únicamente archivos pequeños y aprobados para las
personas que participen en la clase.

- `guides/`: guías y documentación descargable.
- Los ejemplos reproducibles viven en `examples/` para conservar juntos el
  código, las pruebas y sus instrucciones.
- Los audios, paquetes y otros binarios grandes se publican como activos de una
  versión de GitHub y se enlazan desde `materiales.qmd`.

Antes de incorporar datos, se debe registrar su fuente, fecha de descarga,
licencia y cualquier transformación. Los datos privados, restringidos o
identificables no se publican en este repositorio.
